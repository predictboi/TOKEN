# INFINITE BOND (가칭) · 계획서 v3

작성일: 2026-09-10
기준: Sanctum INF 연동. 도식·차트가 포함된 페이지 원본은 `docs/infinite-bond.html`.

## 한 문장

팀이 INF로 본드를 걸고, 홀더가 약속 파기 보호를 사고, 6개월 이력이 신용등급이 된다. 본드는 잠겨 있는 동안 Sanctum Infinity의 스테이킹 수익(연 6.4%)을 낸다.

## 왜 INF인가

| 효과 | 내용 |
|---|---|
| 팀의 비용이 사라진다 | 본드 500 SOL 상당이 6개월간 약 16 SOL을 번다 |
| 팀이 가진 돈으로 낸다 | 조달금 SOL을 Sanctum Router에서 INF로 바꿔 그대로 건다 |
| 원금이 안 깎인다 | LP와 달리 비영구 손실이 없다. 정산 로직이 v2와 동일 |

## 단위 원칙

프로그램 안의 모든 금액은 INF 단위. 달러는 프론트에서만 환산(Sanctum 가격, 폴백 Jupiter). 구매 화면에 "이 보호는 SOL 기준" 문구 고정.

## 돈의 흐름 (본드 500 SOL 상당)

| 결말 | 홀더 | 팀 | 프로토콜 |
|---|---|---|---|
| 6개월 Pass | 보험료 76.4 소멸 | 500 + 68.7 + 스테이킹 16.0 = 584.7 | 7.6 (+ 파트너 2.5) |
| 2개월째 Breach | 보험료 60.7 → 325 + 211.4 = 536.4 수령 | 전액 손실, 등급 D | 6.1 + 슬래시 23.5 |

## 수익 구조

| # | 수익원 | 요율 | 시점 |
|---|---|---|---|
| 1 | 보험료 수수료 | 10% | buy_coverage |
| 2 | 슬래시 수수료 | 남은 본드의 10% | Breach 정산 |
| 3 | 런치패드 통합 | 본드의 0.5% | 파트너 경유 등록 |
| 4 | 등급 API | 월정액 | 6개월 후 |
| 5 | 스테이킹 수익 분배 | v1 0% → v2 최대 20% | 정산 |

월 수익 시나리오(수익원 1~3, 파기율 5%, 파트너 경유 50%): 20건/월 120 SOL, 100건/월 800 SOL, 300건/월 3,000 SOL.

## v2 → v3 개발 변경

| 항목 | 변경 |
|---|---|
| Protocol.bond_mint | 허용 민트 목록 (INF, 데모 테스트 민트) |
| Launch.bond_mint | 런치별 민트 기록. 커버리지·지급 단위 |
| register_launch | 팀의 INF ATA → bond_vault, 민트 검증 |
| 프론트 | INF 수량 + USD 환산, "SOL 기준" 문구, 등록 화면에 Sanctum 스왑 링크 |
| 에러 | BondMintNotAllowed 추가 |
| v2 | Sanctum Router CPI로 SOL → INF 자동 변환, 스테이킹 수익 분배 |

인스트럭션 8개, 계정 4종, 약속 5종, 에러 12종은 `docs/dev-handoff.md`와 동일.

## Sanctum 트랙

1. INF 본드 (해커톤). 요청: INF 채택 확인, 공동 문구, 덱 코멘트.
2. Creator LST 발행사 시장 (액셀러레이터). 약속 3종 추가: 커미션 상한, 딜린퀀시 없음, 스테이크풀 권한 불변. 요청: 10월 런치 예정 팀 2~3곳 소개.
3. 리스테이킹 인수 자본 (v2, Jito Restaking NCN). 약속 파기 = 슬래싱, 보험료 = 리스테이킹 보상.

## 리스크

| 리스크 | 대응 |
|---|---|
| SOL 가격 하락 | INF 단위 고정, "SOL 기준" 문구. 헤지 대상 토큰도 SOL과 같이 움직여 불일치는 USDC보다 작다 |

| 규제 | "약속 시장" 명명, 미국 IP 차단, 팀의 Default 참여 금지 |

## 개발 전 확정

1. 허용 민트: INF + 테스트 민트. USDC 병행은 v2 결정.
2. 최소 본드: 50 SOL 상당.
3. 스테이킹 수익 분배: v1 팀 100%, 이후 최대 20%.
4. USD 환산 가격 소스: Sanctum, 폴백 Jupiter.
5. Creator LST 약속 3종 파라미터: Sanctum과 논의 후.
